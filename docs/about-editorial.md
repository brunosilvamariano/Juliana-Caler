# About Editorial / Quem Somos

Seção 02 do framework premium.

## Estrutura
- Composição editorial sem grid genérico de “foto + texto”.
- Título amplo com destaque azul.
- Três métricas com contagem animada.
- Quote institucional.
- Slider orgânico com 3 imagens WebP locais.
- CTA lateral do slider funciona como “próxima história”.
- Dots clicáveis e autoplay de 5,6 segundos.

## Imagens
As três imagens fornecidas foram preservadas em WebP e renomeadas apenas para manter a arquitetura do framework organizada.


## Métricas — sufixo +

O símbolo `+` de `08+`, `120+` e `40+` é desenhado por `about.css` com `::after`.
Isso mantém o `+` menor e elevado sem ser sobrescrito pela animação do contador em `about.js`.
Os contadores numéricos antigos foram substituídos pelo About Info Pack com conteúdo institucional curto. O inventário ativo foi curado para `vision-mission-values` e `philosophy`.
