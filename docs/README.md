# Documentação do Framework

A documentação é separada por finalidade para não misturar estado atual com histórico.

- `architecture.md` — arquitetura geral.
- `css-architecture.md` — cascata, layers e política sem `!important`.
- `section-design-system.md` — tokens de shell, topline, títulos e copy das seções internas.
- `customization.md` — como personalizar sem disputar especificidade.
- `content-engine.md` — conteúdo JSON, manifest e fallback HTML.
- `variant-registry.md` — inventário oficial das variantes.
- `semantics-accessibility.md` — semântica e acessibilidade.
- `release-checklist.md` — checklist de entrega.
- `legal-and-rights.md` — direitos e distribuição.
- `audits/` — relatórios de auditoria.
- `releases/` — histórico de releases.
- `history/` — documentos técnicos antigos mantidos apenas como referência.

Documentos editoriais específicos de seções permanecem em `docs/` porque ainda servem como referência de implementação.
