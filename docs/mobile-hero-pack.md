# Hero responsivo — variantes curadas

O pacote responsivo acompanha apenas as cinco variantes atualmente suportadas pelo Hero.

- `organic`: preserva uma leitura orgânica mais suave.
- `diagonal`: mantém o recorte geométrico em proporção adequada à tela.
- `split`: vira uma divisão vertical limpa, com conteúdo antes da mídia.
- `arch`: mantém o arco e suporta retrato PNG/WebP transparente ancorado na base, sem fundo ou overlay artificial.
- `banner`: preserva a experiência de mídia em tela cheia com prioridade para legibilidade.

O objetivo não é reproduzir o desktop em escala menor, mas preservar a identidade de cada composição sem comprometer leitura, enquadramento ou interação.
