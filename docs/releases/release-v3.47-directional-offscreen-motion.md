# v3.47 — Directional Offscreen Motion

Esta versão substitui a linguagem visual da v3.46 por um sistema de entrada direcional perceptível.

- Hero: entrada vertical mascarada + mídia vindo da direita.
- About: texto vindo da esquerda + imagem vindo de baixo.
- Serviços: alternância esquerda/direita.
- Projetos: cards vindo de baixo do grid.
- FAQ: entrada pela direita.
- Contato: entrada pela esquerda.
- Adicionado `css/base/motion-directional.css` para conter as entradas fora da composição.
- Mantidos os layouts, conteúdos, links, variações e comportamento funcional das seções.
