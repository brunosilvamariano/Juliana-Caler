# V3.27 — About Image Pack

Dez variações visuais para o slider do About.

## Variantes
1. `organic`
2. `soft-wave`
3. `diagonal`
4. `arch`
5. `capsule`
6. `asymmetric`
7. `ticket`
8. `fluid`
9. `frame`
10. `split-curve`

## Definir no HTML
```html
<div class="about-editorial__visual" data-about-image-variant="organic">
```

As cores decorativas ficam contidas ao redor da mídia e usam variáveis CSS:
```css
--about-media-accent
--about-media-accent-strong
--about-media-accent-soft
--about-media-line
```

O slider, autoplay, dots e botão de próxima imagem continuam compartilhados por todas as variantes.

Nenhuma imagem foi criada ou alterada.
