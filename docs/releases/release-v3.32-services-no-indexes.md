# V3.32 — Services sem índices 01–05

Os números `01`, `02`, `03`, `04` e `05` foram removidos dos itens da seção Serviços.

## Motivo

A seção já possui hierarquia suficiente por título, imagem, tags e CTA. A retirada dos índices deixa principalmente as variantes `focus-card` e `modular-blocks` mais clean.

## Ajustes estruturais

As colunas CSS de todas as seis variantes foram redistribuídas para aproveitar o espaço anteriormente reservado aos números:

- editorial-grid
- stacked-panels
- horizontal-split
- focus-card
- minimal-list
- modular-blocks

Tablet e mobile também foram ajustados.

Nenhuma imagem, texto de serviço, link de WhatsApp ou interação foi removida.
