# v3.11 — Banner + Stacked + Marquee

## Hero
- A variante `stacked` foi redesenhada como um deck de dois cards grandes sobrepostos.
- A variante `dual` permanece intacta.
- Criada a variante `banner`, onde a fotografia ocupa toda a largura e altura útil do Hero.
- O motor do Hero agora reconhece 12 variantes.

## Marquee
A tipografia foi aumentada moderadamente em desktop, tablet e mobile,
mantendo limites responsivos com `clamp()`.

## Como testar
```html
data-hero-variant="stacked"
```

```html
data-hero-variant="banner"
```
