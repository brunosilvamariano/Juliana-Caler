# v3.53 — FAQ Variants

- Sistema de variantes para FAQ via `?faq=`.
- `premium-panel`: versão principal/original preservada.
- `editorial-split`: alternativa arquitetônica.
- `focus-stack`: alternativa focal em pilha.
- Documentação em `docs/faq-variants.md`.
- Entrada dos itens do FAQ consolidada em stagger coordenado para evitar atraso acumulado.

- Conteúdo das perguntas e respostas.
- Acessibilidade e sincronização ARIA.
- Uma pergunta aberta por vez.
- FAQ atual sem alterações visuais quando `premium-panel` é usado ou quando não há parâmetro.
