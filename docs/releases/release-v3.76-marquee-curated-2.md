# Release v3.76 — Marquee Curated 2

## Objetivo

Reduzir o Marquee a duas variantes oficiais, mantendo apenas soluções visualmente distintas e diminuindo o custo de manutenção do framework.

## Mantidas

- `modern-clean`
- `soft-outline`

## Removidas do runtime

- `premium-gradient`
- `accent-mix`
- `elegant-glow`
- `mono-luxury`

As variantes removidas permanecem citadas apenas em documentação histórica de releases/auditorias anteriores.

## Movimento preservado

Nenhuma alteração foi feita na lógica de movimento do Marquee: direção vinculada ao scroll, velocidade acumulada, inércia curta, parada quando o scroll para e ausência de autoplay.
