# Contribution Policy

This is a proprietary framework and does not accept public contributions by default. A pull request, patch, suggestion or code submission does **not** automatically grant the submitter rights to the Framework and does not automatically transfer the submitter's copyright.

Only submit material you have the right to provide. Third-party code or assets must include source, version and license information. Any accepted contribution should have its ownership/license terms agreed in writing before incorporation when authorship rights could be relevant.

Technical contributions must preserve the project rules documented in `README.md`, `docs/architecture.md`, `docs/variant-registry.md`, `SECURITY.md` and the current release notes.
